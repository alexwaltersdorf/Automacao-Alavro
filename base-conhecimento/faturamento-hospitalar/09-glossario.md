# 09 — Glossário de Faturamento Hospitalar

| Termo | Significado |
|---|---|
| **AIH** | Autorização de Internação Hospitalar — documento/nº que autoriza e fatura internações no SUS |
| **AMB** | Associação Médica Brasileira — publica a CBHPM e as tabelas AMB (90/92/96) |
| **ANS** | Agência Nacional de Saúde Suplementar — regula operadoras e o padrão TISS |
| **APAC** | Autorização de Procedimento de Alta Complexidade (ambulatorial SUS) |
| **BPA (C/I)** | Boletim de Produção Ambulatorial (Consolidado / Individualizado) — SUS |
| **Brasíndice** | Guia de preços de medicamentos usado na valoração de contas |
| **Case-mix** | Perfil de complexidade dos pacientes atendidos |
| **CBHPM** | Classificação Brasileira Hierarquizada de Procedimentos Médicos (AMB) |
| **CBO** | Classificação Brasileira de Ocupações — identifica a profissão nos sistemas |
| **CH** | Coeficiente de Honorários — unidade de valor das tabelas AMB antigas |
| **CID-10/11** | Classificação Internacional de Doenças — diagnóstico |
| **CMED** | Câmara de Regulação do Mercado de Medicamentos (teto de preços) |
| **CNES** | Cadastro Nacional de Estabelecimentos de Saúde |
| **CNS** | Cartão Nacional de Saúde (identificador do usuário SUS) |
| **Competência** | Mês de referência de apresentação da produção/conta |
| **Conta aberta** | Cobrança item a item (fee-for-service) |
| **DRG** | Diagnosis Related Groups — agrupamento por complexidade para remuneração |
| **Demonstrativo** | Retorno eletrônico da operadora (análise/pagamento) no padrão TISS |
| **Elegibilidade** | Verificação de que o beneficiário tem direito ao atendimento |
| **Fator de qualidade** | Índice ANS aplicado ao reajuste de contratos (Lei 13.003) |
| **Glosa** | Não pagamento total/parcial de item apresentado |
| **Guia** | Formulário/mensagem TISS de solicitação ou cobrança |
| **Honorário** | Remuneração do trabalho médico |
| **Intercâmbio** | Atendimento de beneficiário de outra singular (ex.: sistema Unimed) |
| **Junta médica** | Mecanismo de resolução de divergência clínica entre solicitante e operadora |
| **Lote** | Conjunto de guias enviado à operadora (XML TISS) |
| **OPME** | Órteses, Próteses e Materiais Especiais |
| **Pacote** | Valor fechado contratado para procedimento/evento |
| **PF / PMC** | Preço Fábrica / Preço Máximo ao Consumidor (medicamentos) |
| **Porte** | Escala de valor do trabalho médico na CBHPM (1A–14C); porte anestésico 0–8 |
| **Prorrogação** | Solicitação de diárias/tratamento adicional em internação |
| **Protocolo** | Comprovante de entrega da conta — marco para prazos |
| **Recurso de glosa** | Contestação formal da glosa com evidências |
| **SADT** | Serviço Auxiliar de Diagnose e Terapia (exames e terapias) |
| **Senha** | Nº de autorização emitido pela operadora |
| **SIA/SUS** | Sistema de Informações Ambulatoriais do SUS |
| **SIGTAP** | Tabela de Procedimentos, Medicamentos e OPM do SUS |
| **SIH/SUS** | Sistema de Informações Hospitalares do SUS |
| **Simpro** | Base de preços de materiais (e alguns medicamentos) |
| **SISAIH01** | Aplicativo de digitação/exportação de AIH no hospital |
| **SP/SH** | Serviço Profissional / Serviço Hospitalar (componentes de valor SIGTAP) |
| **TISS** | Troca de Informações na Saúde Suplementar — padrão obrigatório ANS |
| **TUSS** | Terminologia Unificada da Saúde Suplementar (códigos usados no TISS) |
| **UCO** | Unidade de Custo Operacional da CBHPM |
| **XML TISS** | Formato eletrônico dos lotes de guias e demonstrativos |
